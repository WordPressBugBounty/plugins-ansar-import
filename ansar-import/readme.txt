== Description ==

**Stop building from scratch.** **Ansar Import** is your all-in-one **Starter Sites, One-Click Demo Importer, and In-Editor Template Library** for WordPress.

Instead of spending hours configuring themes, plugins, menus, and layouts, Ansar Import lets you launch a complete, pixel-perfect website in seconds—and keeps working for you every day with an **in-editor library of ready-made page & section templates** right inside the WordPress Block Editor.

= Why Choose Ansar Import? (And Why Keep It Active) =

Most demo importers are "use once and delete" tools. **Ansar Import is built to stay with you as your ongoing design companion:**

* **Launch Full Websites in 1 Click** – Pick from 100+ professionally designed Starter Sites for **Elementor**, **Gutenberg Block Editor**, and **Classic Themes**.
* **In-Editor Section & Page Template Library** – Building a new landing page, About page, or blog post next month? Open the **Ansar Template Library** directly inside the WordPress Block Editor to insert pre-built hero sections, post grids, callouts, and full-page layouts on the fly.
* **Works With Your Favorite Theme** – Seamlessly compatible with popular WordPress themes including **Astra**, **Neve**, **Blocksy**, Full Site Editing (FSE) Block Themes, and all ThemeAnsar themes.
* **Zero Frontend Bloat** – Ansar Import only loads its scripts in the admin dashboard and editor when you need them, adding **0 KB** to your public website's page speed.

= Key Features =

* **Guided Setup Wizard** – Launches automatically upon activation so you can choose your preferred editor (**Block Editor**, **Elementor**, or **Classic**) and import a starter site in minutes.

* **Live In-Editor Template Library** – Browse, search, and insert 100s of Gutenberg section patterns and full-page templates without leaving the page editor.

* **High-Speed CDN Failover Engine** – Powered by automatic jsDelivr CDN mirror failover so demo downloads never stall or timeout on shared hosting.
* **Real-Time Import Progress Bar** – Watch every step of your theme, plugin, and content setup in real time.

= How It Works =

1. **Install & Activate** – Activate **Ansar Import** and the **Setup Wizard** will open automatically (or go to **Ansar Import > Starter Sites** in your dashboard).
2. **Choose Your Editor** – Filter starter sites by **Block Editor (Gutenberg)**, **Elementor**, or **Classic Theme**.
3. **Preview & Click Import** – Select what to import (Content, Widgets, Customizer Settings) and click **Import**.
4. **Keep Building Anytime** – Open any page or post in the WordPress Block Editor and use the **Ansar Template Library** button to insert new sections and page layouts whenever your site grows!

== Installation ==

= Automatic Installation (Easiest) =

1. Log in to your WordPress dashboard and navigate to **Plugins > Add New Plugin**.
2. Search for **Ansar Import**.
3. Click **Install Now**, then click **Activate**.
4. You will be automatically redirected to **Ansar Import > Starter Sites** to pick your preferred editor and import your first starter site!

= Manual Installation =

1. Download `ansar-import.zip` from WordPress.org.
2. In your WordPress dashboard, go to **Plugins > Add New Plugin > Upload Plugin**, choose the zip file, and click **Install Now**.
3. Click **Activate Plugin** and open **Ansar Import > Starter Sites** from your admin sidebar.

More details are available in the official WordPress documentation on [Manual Plugin Installation](https://developer.wordpress.org/advanced-administration/wordpress/install-plugin/#manual-plugin-installation).

= Updating =

Automatic updates work seamlessly through your WordPress dashboard. Keep the plugin updated to access newly released starter sites and section templates.

== Frequently Asked Questions ==

= Does Ansar Import work with Astra, Neve, and Blocksy? =

**Yes!** Ansar Import is fully compatible with **Astra**, **Neve**, **Blocksy**, and other popular WordPress themes:
* You can import **Block Editor (Gutenberg)** and **Elementor** starter sites and use the **In-Editor Section & Page Template Library** directly on Astra, Neve, Blocksy, or any Full Site Editing (FSE) Block Theme.
* If you select a classic starter site built for a specific free [ThemeAnsar](https://themeansar.com/) theme (such as Newsup, Blogus, Newses, Newsxo, or Blogier), Ansar Import can also automatically install and activate that free theme from WordPress.org for you in one click.

= Should I keep Ansar Import active after importing a starter site? =

**Yes!** Keeping Ansar Import active gives you ongoing access to the **In-Editor Section & Page Template Library** inside the WordPress Block Editor whenever you create new pages or posts, plus instant access to new starter templates as they are released. Because Ansar Import only runs in the admin area when used, keeping it active adds **zero frontend load** to your website.

= What happens if I deactivate Ansar Import later? =

All imported pages, posts, images, menus, widgets, and customizer settings are saved permanently in your WordPress database. Your website will continue to work normally, though you will lose access to the in-editor Section & Page Template Library until you reactivate it.

= Does Ansar Import work with both Elementor and Gutenberg Block Editor? =

Yes! Ansar Import includes a built-in editor switcher supporting **Gutenberg / Block Editor**, **Elementor**, and **Classic Theme** starter sites.

= Will importing a demo overwrite my existing posts or pages? =

No, importing a starter site will not delete your existing posts or pages. However, for the cleanest result that matches the live demo preview, we recommend importing a full starter site on a fresh WordPress installation, or using the **In-Editor Template Library** to insert individual sections/pages on an existing site.

= What if my hosting server is slow or blocks GitHub downloads? =

Ansar Import features a built-in **jsDelivr CDN failover engine** and automatic timeout recovery, ensuring demo content, widgets, and customizer files download reliably even on restricted or shared hosting environments.
